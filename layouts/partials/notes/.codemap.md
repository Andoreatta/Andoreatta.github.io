# layouts/partials/notes/
## Responsibility
Chrome shared by the notes pipeline: the recursive section menu (`nav.html`), index card grid (`cards.html`), related links (`related.html`), intra-section pager (`prevnext.html`) and the placeholder-filling form (`ph-vars.html`). Consumed only by `layouts/notes/{single,list}.html`; no page here owns a full document.

## Design
- `nav.html`: `site.GetPage "/notes"` is the root; renders `<details id="notes-nav" open>` with a `<summary>` carrying the current page title + "menu" hint. `.Pages.ByWeight` is walked; sections recurse through the named template `notes-nav-section` (defined at the bottom of the same file, so recursion is a template call, not a second file). Active detection = current page equals the node or its `RelPermalink` has the section's `RelPermalink` as prefix (`is-active` class); exact matches get `aria-current="page"`. Notes with `task = true` get the `notes-nav__checklist` class.
- `nav.html` inline script: on `matchMedia('(max-width: 960px)')`, `nav.open` is forced closed on narrow / open on wide. `centerActive()` scrolls `nav.scrollTop` so the `a[aria-current="page"]` sits mid-box, and is re-run on `toggle` when opened. Legacy `addListener` fallback for old Safari.
- `cards.html`: heading text depends on context — `Sections` at `/notes/`, `Sections and pages` when the current page has `.Sections`, otherwise `Pages`. Sections show `.Description | plainify` plus `len .RegularPagesRecursive` with singular/plural; leaves show `.Summary | plainify | truncate 150`. Grid is `data-pagefind-ignore="all"` so cards never inflate the index with duplicated titles/summaries.
- `related.html`: `where (site.RegularPages.Related $page) "Type" "notes" | first 4`; section is labelled by `aria-labelledby="related-notes"`. Ranking comes from `[related]` in `config/_default/hugo.toml` (threshold 20, tags weight 100, `includeNewer`).
- `prevnext.html`: reads `.CurrentSection.RegularPages.ByWeight`, linear-scans for the current page's index, then takes `index-1` / `index+1`. Section pages themselves are never in the chain; first/last render only one arrow.
- `ph-vars.html`: static form, no server round-trip. Six labelled inputs with `data-ph="IP|ATTACKER|LPORT|DOMAIN|USER|PASS"`; text fields disable autocomplete/autocapitalize/spellcheck, port uses `inputmode="numeric"`, password uses `autocomplete="new-password"`. Whole section is `data-pagefind-ignore` so example values and labels stay out of search. `[data-ph-clear]` is a plain button; all behaviour is in `assets/js/notes.js`.

## Flow
- `layouts/notes/single.html` → `notes/nav.html` → `site.GetPage "/notes"` → `.Pages.ByWeight` → `template "notes-nav-section" (dict "section" . "page" $page)` → nested `<ul>` → browser script syncs `open` + scroll.
- `layouts/notes/list.html` → `notes/cards.html` (before `.Content` at `/notes/`, after it on subsections) → `.Pages.ByWeight` → card `<a>` → section count or leaf summary.
- `single.html` footer → `notes/related.html` → `site.RegularPages.Related` (tags index) → first 4 note permalinks; → `notes/prevnext.html` → `CurrentSection.RegularPages.ByWeight` → prev/next anchors.
- `single.html` `if .Params.phVars` → `notes/ph-vars.html` → `notes.js` `document.querySelector('.ph-vars')` → `input[data-ph]` map → `sessionStorage["srl-ph-vars"]` (PASS excluded) → `<IP>`-style tokens wrapped in `.notes-article .content pre` → `[data-ph-clear]` removes the key and empties fields.
- `notes.js` also injects `data-pagefind-ignore` on heading anchors and copy buttons created inside the article.

## Integration
- Called by: `layouts/notes/single.html` (nav, ph-vars, related, prevnext), `layouts/notes/list.html` (nav, cards).
- Depends on: `assets/js/notes.js` (ph-vars, checklist, copy buttons), `assets/css/custom.css` (`.notes-nav*`, `.notes-cards`, `.notes-prevnext`, `.notes-related`, `.ph-vars*`), front matter `phVars` / `task`, `[related]` config, Pagefind directives.
- Consumed alongside: `layouts/partials/running-lain.html`, `layouts/partials/head/meta.html` (OG `see_also` also uses Hugo's related index).
