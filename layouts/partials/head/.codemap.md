# layouts/partials/head/
## Responsibility
Vendored overrides of the theme's three head partials. `themes/hugo-brewm/layouts/partials/head.html` calls `partial "head/meta.html" .` (per page, uncached), then `partialCached "head/js.html" .` and `partialCached "head/css.html" .` (one build-wide bundle). These files exist to fix SEO/perf/security defects without forking the theme.

## Design
`meta.html` (diff vs theme):
- Canonical for paginated terms: `.Permalink` always points at page 1, so for `Kind == "term"` it calls `partial "paginator.html" .` (defined in `themes/hugo-brewm/layouts/partials/bundles/branch.html`, same args as the list template so `.Paginate` is not re-invoked) and uses `.URL | absURL` plus `.PageNumber`; page > 1 rewrites the title to `… — Page N | site`.
- Home `<title>` carries the site description (`siteTitle — siteDesc`); other pages keep `title | site`.
- `WebSite` JSON-LD is emitted on the home page only; posts get `BlogPosting` from `_default/single.html`.
- Descriptions: theme replaced every non-page description with `"<kind> | site"`. Override keeps the real `.Summary`/`.Description` and only synthesises per-kind copy for `term` (tag-specific sentence) and `taxonomy`, falling back to `title — siteDesc`.
- hreflang cluster is emitted only when `.IsTranslated`, is self-referential (current language first), lists `.Translations`, and adds `x-default` pointing at the `en` translation. Monolingual notes stay unannotated.
- `og:locale` from `site.Language.Locale | default Lang` with `-`→`_`; `og:locale:alternate` per translation.
- `article:*` bug fix: the OpenGraph dict has no `.IsPage`, so the theme's `if .IsPage` was always false; the override tests `.page.IsPage`. Related/`og:see_also` likewise use `.page` and compare `.Permalink` to `$.page.Permalink` (theme compared page objects to a dict key).
- `og:image:alt/width/height` (1200×630) and `twitter:image:alt` added; `X-UA-Compatible` removed.
- Thin terms: `Kind == "term"` with `< 3` pages gets `<meta name="robots" content="noindex, follow">`, matching `$minTermPages` in `layouts/_default/sitemap.xml`.

`css.html`:
- `print.css` removed from the concatenated `hugo-brewm.css` order (`baseSty + baseFonts + extrasSty + custom`).
- Print ships separately as `minify | fingerprint "sha256"` with `media="print"`, so it never blocks rendering.
- Fingerprint is computed on the *executed+minified* template and both `RelPermalink` and `Data.Integrity` come from that same object — filename and SRI hash can no longer diverge (theme printed the un-fingerprinted `.Permalink`). Dev mode uses `RelPermalink`, not the absolute `Permalink`.

`js.html`:
- Global bundle = `default.js + accessibility.js + bionread.js` (+`extras.js` unless `BearMode`/`ZenMode`).
- `qrcode.js` (≈14 KB, colophon only) is no longer appended here; `layouts/_default/single.html` loads it only for `post`/`articles` with colophon enabled.
- Same fingerprint/SRI coherence fix as CSS.

## Flow
- Every page: `baseof.html` → `partial "head.html"` → `head/meta.html` (canonical/description/OG/Twitter/JSON-LD per page) → `partialCached "head/js.html"` → `partialCached "head/css.html"` → `partial "head/css/inline.html"`.
- Term page: `meta.html` → `partial "paginator.html"` → `.Paginate .RegularPagesRecursive [.Params.Paginate]` → `.URL`, `.PageNumber` → `<link rel="canonical">`, `<title>`, `og:url` (the canonical value is passed into the OpenGraph dict).
- CSS: `resources.Get` typefaces → conditional `typeface-local` swap → concat `hugo-brewm.css` → `ExecuteAsTemplate` → `minify` → `fingerprint` → `<link>` + `media="print"` link for print.
- JS: `slice` → optional `extras.js` → concat `hugo-brewm.js` → `ExecuteAsTemplate` → `minify` → `fingerprint` → deferred `<script>` with `integrity`.
- Colophon QR: `layouts/_default/single.html` `head` block → `resources.Get "js/qrcode.js"` → fingerprinted script; DOM target `#qr` from `partials/post/colophon.html` (defined in `bundles/leaf.html`).

## Integration
- Invoked by: `themes/hugo-brewm/layouts/partials/head.html`, itself called from `themes/hugo-brewm/layouts/_default/baseof.html` and `fullscreen/baseof.html`.
- Depends on: `partials/paginator.html` (theme `bundles/branch.html`), `partials/page/cover.html` and `partials/head/meta/favicon.html` (defined in `bundles/leaf.html` / this file), `partials/fediverse/meta.html`, `assets/css/**`, `assets/js/**`, `site.Params.socialCard`, `site.Params.typeface`, `site.Params.BearMode/ZenMode`.
- Consumed alongside: `layouts/partials/analytics.html` (CSP/preload), `layouts/_default/sitemap.xml` (same `<3` term threshold).
- Constraint: because `js.html`/`css.html` are `partialCached` without a variant, they must stay page-independent; per-page scripts belong in page `head` blocks (as `notes/single.html` does for `notes.js`).
