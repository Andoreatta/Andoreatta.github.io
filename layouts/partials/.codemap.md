# layouts/partials/
## Responsibility
Site-wide overrides that are not component-scoped: `analytics.html` (security headers, font preload, language routing), `footer.html` (body footer plus the `main/footer.html` template), `running-lain.html` (decorative notes sigil). Component chrome lives in `head/`, `notes/`, `search/`, `ascii/`.

## Design
### analytics.html
Deliberately *not* analytics: `params.analytics.append = 'head'` makes `baseof.html` call `partialCached "analytics.html"` inside `<head>`, so the meta tags land before any body content.

- Emits `theme-color`, `color-scheme`, `Referrer-Policy` (`strict-origin-when-cross-origin`) and a **meta CSP** — GitHub Pages cannot set response headers, so this is the only delivery channel.
- Directive choices:
  - `default-src 'self'` — deny by default.
  - `script-src 'self' 'unsafe-inline' https://cdn.jsdelivr.net` — `'unsafe-inline'` is mandatory: the theme's `accessibility.js` injects `onclick=` handlers into `#has-a11y`/`#focusMode`, and the site ships inline blocks for flashguard, TOC/nav sync, Pagefind init and the language redirect. Hashes cannot cover runtime-injected handlers. jsDelivr is allowed for KaTeX/MathJax/hljs.
  - `style-src 'self' 'unsafe-inline' https://cdn.jsdelivr.net` — `accessibility.js` appends a `<style>` element and markup uses inline `style=`; KaTeX CSS comes from the CDN.
  - `img-src 'self' data: https://duckduckgo.com` — the no-JS search fallback renders the DuckDuckGo logo.
  - `font-src 'self' data: https://cdn.jsdelivr.net` — self-hosted Atkinson/OpenDyslexic plus KaTeX fonts.
  - `connect-src 'self'` — Pagefind fetches its index/wasm from `/pagefind/`.
  - `worker-src 'self' blob:` — Pagefind spawns its worker from a blob URL.
  - `base-uri 'self'`, `object-src 'none'`, `frame-src 'none'`, `form-action 'self' https://duckduckgo.com` — block `<base>` rewriting, plugins, framing and off-site posts.
  - `frame-ancestors`, `report-uri`, `sandbox` are ignored in meta CSP; HSTS / `X-Content-Type-Options` require a proxy in front of Pages.
- Preloads `fonts/atkinson-hyperlegible/atkinson-hyperlegible-regular.woff2` (`as="font"`, `crossorigin`) to cut CLS/FOUT.
- Language routing: key `srl-exp-lang`. Returns immediately on pt pages or when the stored preference is `en`; otherwise uses `localStorage` preference or `navigator.languages` to detect Portuguese, finds `link[rel="alternate"][hreflang^="pt"]` (emitted by `head/meta.html`) and `location.replace()` preserving `search` + `hash`. If no translation exists, the reader stays. A delegated `click` listener on `#bi18n, #i18n-menu, #has-l10n` records deliberate switches. No JS → no redirect, theme switcher still works.

### footer.html
- Body footer: `#body-footer` with `#background-footer`, `#focusMode`, `partialCached "a11y.html"`, `#useBionRead`, and a `#to-top` bypass link. These are the mount points `assets/js/accessibility.js` mutates.
- Difference vs theme: the top nav's `aria-label` uses `i18n "toTop"` instead of `i18n "bypass"` (theme mislabelled the link).
- Defines `partials/main/footer.html` (footer content columns built from `where .Site.RegularPages "Type" "footer"`, footer menu, unified license/coffee block); `baseof.html` calls it inside `#exclude`.

### running-lain.html
Single decorative `<div class="running-lain [class]">` with `aria-hidden="true"` and `data-pagefind-ignore`; visual comes from CSS pseudo-elements. Context is a dict with optional `class`.

## Flow
- `<head>`: `baseof.html` → `partialCached "analytics.html" .` → CSP meta + referrer meta + font preload + language script → `document.documentElement.lang` read → alternate-link lookup → optional redirect.
- Body: `baseof.html` → `partialCached "footer.html"` → `#body-footer` → `partialCached "a11y.html"` → `assets/js/accessibility.js` (`getElement('has-a11y')`, `#background-footer`, `#focusMode`, `#useBionRead`) → injected UI.
- Footer content: `baseof.html` `#exclude` → `partialCached "main/footer.html"` (defined here) → `menu.html`, `coffeeStat.html`.
- Language switch click: `<a>` inside `#bi18n` → delegated listener → `localStorage["srl-exp-lang"] = 'pt-br' | 'en'` → next first-visit check honours it.

## Integration
- Called by: `themes/hugo-brewm/layouts/_default/baseof.html` (head + body), `layouts/notes/{single,list}.html`, `layouts/_default/**`, `layouts/shortcodes/**`.
- Depends on: `partials/a11y.html`, `partials/menu.html`, `partials/coffeeStat.html`, `assets/js/accessibility.js`, `assets/fonts/atkinson-hyperlegible/*`, `config/_default/hugo.toml` (`params.analytics.append`, `params.coffeeStat`, `params.unifiedFooter`), i18n keys `toTop`.
- Interacts with: `layouts/partials/head/meta.html` (hreflang links consumed by the redirect), `layouts/partials/search/*` (CSP `connect-src`/`worker-src`), `layouts/partials/ascii/*` (decorative-content convention).
