# layouts/_default/

## Responsibility
Fallback templates for anything not claimed by a section-specific layout: single pages (posts, about, standalone pages) and the site-wide XML sitemap. `baseof.html` and `list.html` are **not** overridden and resolve to `themes/hugo-brewm/layouts/_default/`.

Lookup order: `layouts/notes/single.html` wins for the `notes` section; `layouts/_default/single.html` handles the rest. Both extend the theme `baseof.html`. `sitemap.xml` has no per-section variant and applies to every output language.

## Design
### single.html
Overrides three of the theme baseof blocks (`head`, `main`, `exclude`); `aside`, `top` and `post` stay empty.

- **head** — conditional asset loading, plus a `BlogPosting` JSON-LD graph for `post`/`articles` (Organization publisher, author URL, `inLanguage`; notes keep their own `TechArticle`):
  - KaTeX CSS only when `.Page.Store.Get "hasMath"`, set by the theme's `_markup/render-passthrough.html` when `$$`/`\begin{}` blocks are actually parsed.
  - `head/js/katex.html` for `.Params.Math` or `.Params.katex`, else `head/js/mathjax.html` for `.Params.MathJax`.
  - `head/js/hljs.html` only when `.Params.Hljs`.
  - `qrcode.js` only when `.Params.type` is `post`/`articles` **and** `.Params.colophon` or `site.Params.posts.colophon`. The colophon is the only QR consumer (`extras.js` guards on `typeof QRCode`). This is the site addition: the theme bundled qrcode into every page via `head/js.html`.
- **main** — series/stage chips from `.GetTerms`; `article#main-article` with `sf`/`rm` from `site.Params.Posts.sfdefault` / `.Params.sfdefault`; `data-pagefind-body` for post/articles vs `data-pagefind-ignore="all"` otherwise; title/author/timestamp partials; optional TOC and audio; content with `disabled=` stripped through `safeHTML` when `.Params.task` or `site.Params.Post.enableCheckbox`; tag footer for posts.
- **exclude** — related, colophon, history, contribute, share nav, then giscus or fediverse comments. Site drops the theme's redundant `role="contentinfo"` from `div#contentinfo`.

### sitemap.xml
- Base set: `.Pages` minus `Headless` and `Sitemap.Disable`.
- Excludes `Kind == "taxonomy"` (tag/category indexes) and `Kind == "term"` with fewer than 3 pages. Thin terms stay crawlable through navigation but are not advertised.
- `lastmod` when non-zero; `changefreq` only when a page sets `Sitemap.ChangeFreq` (no global default); `priority` when set.
- hreflang: one entry per translation, a self entry for the page's own language, and `x-default` pointing at the `en` translation.
- Theme fixes: hreflang uses `.Language.Lang` instead of locale, valid closing nesting, no `<!-- internal template -->` comment.

## Flow
Build → lookup (`layouts/notes/single.html` or `_default/single.html` → theme) → theme `baseof.html` → `head` block (`head.html` → `head/meta.html`, then this file's conditionals) → `main` → `exclude` → partials.

`partial "paginator.html"` contract: defined in `themes/hugo-brewm/layouts/partials/bundles/branch.html`. It calls `.Paginate` on `.RegularPagesRecursive` (or `site.RegularPages` filtered to `post`/`articles` on home) with the optional `.Params.Paginate` size. Hugo memoises it per page, so **every caller must pass the same page and arguments** or the build fails. `layouts/partials/head/meta.html` calls it for `Kind == "term"` to reuse the same result and derive canonical URL + page number, matching the theme `list.html` call: paginated term pages canonicalise to their own page and get a `— Page N` title.

## Integration
- Partials: `page/title.html`, `page/timestamp.html`, `page/cover.html`, `page/audio.html`, `post/tagged.html`, `post/related.html`, `post/colophon.html`, `post/history.html`, `post/contribute.html`, `terms.html`, `nav.html`, `giscus.html`, `fediverse.html`, `head/js/{katex,mathjax,hljs}.html` — defined in the theme bundles unless `layouts/partials/` overrides them.
- Front matter: `type`, `Math`/`katex`/`MathJax`, `Hljs`, `colophon`, `toc`, `task`, `secnum`, `sfdefault`, `related`, `author`, `comments`, `toot`/`mstd`/`mastodon`, `skeet`/`bsky`/`bluesky`, `Headless`, `Sitemap.{Disable,ChangeFreq,Priority}`.
- Params: `Posts.sfdefault`, `posts.{colophon,related,share,disableHistory,secnum}`, `Post.enableCheckbox`, `BearMode`, `ZenMode`, `comments.disabled`, `giscus`.
- Downstream: the generated `sitemap.xml` must remain well-formed XML for the Pages deploy; thin-term filtering must stay in sync with the `noindex, follow` rule in `head/meta.html`.
