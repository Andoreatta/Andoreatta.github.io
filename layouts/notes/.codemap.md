# layouts/notes/
## Responsibility
Section templates for `type = "notes"` content (`content/en/notes/**`; notes are English-only — `content/pt-br/` has no notes tree). `single.html` renders one note; `list.html` renders `/notes/` and every subsection index. Both override the theme's `_default` templates by Hugo's section lookup, reuse `themes/hugo-brewm/layouts/_default/baseof.html`, and only fill the `head` / `main` blocks. All reusable chrome lives next door in `layouts/partials/notes/` (not here).

## Design
- No custom `baseof`. `single.html` defines `head` (notes.js + JSON-LD) and `main`; `list.html` defines `main` only.
- `single.html` emits a `TechArticle` JSON-LD graph (`headline`, dates, `Person` author at `/about/`, `Organization` publisher with `/images/social-card.png`, `mainEntityOfPage`, `inLanguage`, `image`, optional `keywords` from `.Params.tags`). `.Description | default .Summary` is plainified and truncated to 220.
- TOC is a `<details id="notes-toc" open>` fed by `.TableOfContents`; an inline script sets `open` from `matchMedia('(max-width: 960px)')` and listens for breakpoint changes. `.Params.toc` is *not* consulted — presence is driven purely by `.TableOfContents`.
- `phVars` front matter (e.g. `content/en/notes/oscp-labs/commands.md`) gates the placeholder form. `task = true` gates a regex that strips `disabled` from task-list checkboxes so they stay interactive.
- Pagefind scoping: `article.notes-article[data-pagefind-body]` is the indexed region; `<h1 data-pagefind-meta="title">` sets the result title. `span.pagefind-filter[data-pagefind-filter="Section"]` sits in the shell *outside* the body so it contributes a filter value, not text. The list's card grid is `data-pagefind-ignore="all"` to avoid re-indexing linked pages; `notes.js` tags injected heading anchors and copy buttons with `data-pagefind-ignore`.
- Attribution is a hardcoded "Adapted from sfoffo's Pentesting Notes" paragraph; credit for list pages comes from `.Params.credit | markdownify`.
- `list.html` ordering depends on depth: at `/notes/` cards render before `.Content`, on subsections `.Content` renders first. Both are wrapped by `notes/nav.html` and end with `running-lain.html`.

## Flow
- Note page: Hugo resolves type `notes` → `layouts/notes/single.html` → `baseof` `main` block → `notes/nav.html` (site.GetPage "/notes" → recursive `notes-nav-section` over `.Pages.ByWeight`) → optional `notes/ph-vars.html` → TOC script → `.Content` (or `replaceRE` de-disabled content) → `notes/related.html` → `notes/prevnext.html` → `running-lain.html` (class `running-lain--notes`).
- Placeholder data: `single.html` renders inputs `[data-ph=IP|ATTACKER|LPORT|DOMAIN|USER|PASS]` → `assets/js/notes.js` collects them, wraps `<IP>` etc. in `.notes-article .content pre` spans, writes all values except `PASS` to `sessionStorage["srl-ph-vars"]`, and restores on load; `[data-ph-clear]` wipes the key.
- Checklist state: `.Params.task` content → `notes.js` hashes each item's label → `localStorage["srl-notes-checklist:<pathname>"]` (with one-time migration from index keys).
- Index page: `.RelPermalink == "/notes/"` → `notes/cards.html` over `.Pages.ByWeight`, then `.Content`; else `.Content` then cards; optional `credit` footer.
- Related: `site.RegularPages.Related $page` (config `[related]` threshold 20, tags weight 100) filtered to `Type "notes"`, `first 4`.
- Prev/next: walk `.CurrentSection.RegularPages.ByWeight`, find the current page's index, take index−1 / index+1.

## Integration
- Consumes: `layouts/partials/notes/{nav,cards,related,prevnext,ph-vars}.html`, `layouts/partials/running-lain.html`, `assets/js/notes.js`, `assets/css/custom.css` (`.notes-*`, `.ph-vars`, `.running-lain`).
- Consumed by: Hugo's section lookup for `content/en/notes/**`; `themes/hugo-brewm/layouts/_default/baseof.html` (`main`/`head` blocks).
- Depends on: Pagefind index built from `data-pagefind-body` (config `params.search.pagefind = true`), `[related]` config in `config/_default/hugo.toml`, front matter `phVars`, `task`, `credit`.
