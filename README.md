# srl.exp.net

Static bilingual blog built with [Hugo](https://gohugo.io/) and the
[hugo-brewm](https://github.com/foxihd/hugo-brewm) theme.

- English: `/`
- Portuguese (Brazil): `/pt-br/`
- Canonical domain: `https://serial.experiments.network/`
- Fallback deployment URL: `https://andoreatta.github.io/`

The theme is tracked as a Git submodule at `themes/hugo-brewm`.

## Local development

Hugo extended 0.168.0 or newer is required.

```sh
git submodule update --init --recursive
hugo server --minify --gc
```

Open the URL printed by Hugo, usually `http://localhost:1313/`.

With search enabled, Pagefind is only generated during a production build:

```sh
hugo --gc --minify
npx pagefind --site public
```

## Writing

English content lives in `content/en/`; Portuguese content lives in
`content/pt-br/`. Posts must use `type = 'post'` in their front matter.

Create a post in one language:

```sh
hugo new content en/posts/my-post.md
hugo new content pt-br/posts/meu-post.md
```

Use the same `translationKey` in both files so the language switcher and the
Portuguese-browser redirect can find the translated version.

## Andoreatta Pentesting Notes and Methodology

The pentesting notes live under `content/en/notes/` and are published in English
only at `/notes/`. They use `type = 'notes'`, which keeps them out of the home
feed and gives them the notes sidebar, index cards, in-page table of contents,
and full-text Pagefind indexing.

The notes are maintained directly in this repository under `content/en/notes/`.
Each section has a hand-written `_index.md` landing page, and every note carries
its own front matter (`type = 'notes'`, `weight`, `toc`, `tags`). To add a note,
create the Markdown file in the matching section directory.

The `/notes/` section cards show a one-line `description` from each section's
front matter. The English and Portuguese homepages carry a compact three-entry
guide that links to the section map, the Lab Field Manual, and the tag index.

Tag pages are generated from the note tags. Tag RSS feeds are intentionally
disabled because they were emitting full note bodies and accounted for most of
the deploy size. The notes index credits
[sfoffo's Pentesting Notes](https://notes.sfoffo.com/) as the original
inspiration and base material.

Notes include copyable code blocks, heading permalinks, related notes, and
persistent checklist state. Search is loaded lazily and can be filtered by
section. Screenshots are stored as WebP with intrinsic dimensions to avoid
layout shift.

Because the notes are full of shell variables (`$TARGET`, `$IP`), `$...$` is
not configured as inline math. Use `$$...$$`, `\(...\)`, or a LaTeX environment
for explicit math.

## About pages

The bilingual About pages live in `content/en/about.md` and
`content/pt-br/about.md`. They contain the public professional profile:
role, focus areas, certifications, compact experience, languages, LinkedIn,
and GitHub.

No phone number, email address, or copy of the source resume PDF is published.
Public contact is limited to LinkedIn and GitHub.

## Language routing

`layouts/partials/analytics.html` contains a small, self-contained script that:

1. Redirects a first-time visitor on an English page to the matching
   Portuguese page when the browser advertises a `pt` language.
2. Does nothing on Portuguese pages.
3. Remembers a manual language choice in `localStorage`, so choosing English
   does not redirect the reader back to Portuguese.

If JavaScript is disabled, the site stays in English and the theme's language
switcher remains available.

## Typography and palette

The site is dark-only and uses a terminal-editorial palette derived from
[fauux.neocities.org](https://fauux.neocities.org/):

- pink accent: `#d2738a`
- tan body text: `#c1b492`
- near-black background: `#0a0a0a`

[Atkinson Hyperlegible](https://www.brailleinstitute.org/freefont) is
self-hosted under `static/fonts/atkinson-hyperlegible/` and loaded through
`assets/css/custom.css`. The font is licensed under the SIL Open Font License
1.1; see `static/fonts/atkinson-hyperlegible/OFL.txt`.

Terminal details — the wordmark, metadata, tags, language switcher, and code —
use the browser's native monospace stack. The homepage portrait is generated by `layouts/shortcodes/lain-hero.html` and
`layouts/partials/ascii/lain.html`.

The portrait is Unicode Braille art. To keep its columns aligned on every
platform, a 3.5 KB subset of Adwaita Mono covering `U+2800–U+28FF` is
self-hosted at `static/fonts/braille/`. It is licensed under the SIL Open Font
License 1.1; see `static/fonts/braille/OFL.txt`. The rest of the site uses the
native mono stack.

The portrait has a single CSS-only horizontal flip every 0.15 seconds, with no
other motion. The animation is disabled under `prefers-reduced-motion`.

The notes pages use a 2560×146 running-Lain sprite strip as a footer. The
6.4 KB, 3-color GIF is animated through CSS `background-position` with the same
smooth 0.3-second linear loop, sliding left-to-right in the direction she faces. The moving dot background is CSS-only
and drifts left-to-right over 240 seconds.

On screens 1200px and wider the layout shell widens to 84rem, to 92rem at
1600px, and to 100rem at 1920px. Note prose is capped at 60rem while code,
tables, and cards use the full article width.

The theme's night clock and flowline illustrations are disabled; the light/dark
switch is hidden because the palette is intentionally dark-only. Contrast,
font-size, OpenDyslexic, focus mode, and the rest of the accessibility panel
remain available.

## Deployment

Pushes to `main` trigger `.github/workflows/hugo.yml`, which builds the site,
runs Pagefind, and deploys to GitHub Pages using GitHub Actions.

The repository is a GitHub user site, so Pages must use:

- **Settings → Pages → Build and deployment → Source:** GitHub Actions

## Custom domain

The code already points at `https://serial.experiments.network/`:

- `baseURL` is set in `config/_default/hugo.toml`
- `static/CNAME` contains the custom domain
- `params.socialCard.images` uses the custom domain

Remaining external steps:

1. At the DNS provider for `experiments.network`, create:

   ```text
   CNAME  serial  andoreatta.github.io
   ```

   If using Cloudflare, set the record to **DNS only** until GitHub provisions
   the certificate.

2. In GitHub, set the custom domain under **Settings → Pages**.
3. Wait for DNS and the certificate, then enable **Enforce HTTPS**.
4. Add the domain to Google Search Console and Bing Webmaster Tools, then submit
   `https://serial.experiments.network/sitemap.xml`.

`AllowAIRobots = true` is set so search and AI crawlers can index the site.
