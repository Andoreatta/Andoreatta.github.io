# i18n/

## Responsibility

Supplies site-level Brazilian Portuguese translations that the `hugo-brewm` theme does not already ship. Only missing `pt-br` keys live here; everything else resolves from `themes/hugo-brewm/i18n/pt_br.toml`. The file exists so the Portuguese UI can be completed without forking the theme or duplicating its 106 existing keys.

## Design

- **Delta-only catalogue.** The theme's `en.toml` has 119 top-level keys (134 leaf keys including plural forms); its `pt_br.toml` has 106 (120 leaves). This directory adds the 13 missing top-level entries (14 leaves, because `posts` carries `one`/`other`), and Hugo's i18n merge lets site values override or extend the theme per key.
- **Filename convention.** The site file is `pt-br.toml` (hyphen) while the theme uses `pt_br.toml` (underscore); both resolve to the `pt-br` language, and the site catalogue is read after the theme's.
- **Key categories supplied here:**
  - *UI chrome:* `pagination`, `posts`, `postsBy`, `postsOn`, `poweredBy`, `prev`, `print`, `published`, `readingTime`, `recent`.
  - *Notes UI:* `redactionHistory`, `redactionNotes`.
  - *Accessibility/colour-vision:* `protanopia`.
- **Categories left to the theme:** `search` and the a11y keys (`accessibility`, `contrast`, `dark`, `light`, `monochrome`, `deuteranopia`, `tritanopia`, `OpenDyslexic`, etc.) already exist in `pt_br.toml` and are not repeated here.
- **Pluralisation.** Entries that vary by count use Hugo's `one`/`other` forms (`posts.one`, `posts.other`); the rest use `other` only.

## Flow

Templates call `i18n "key"` (169 call sites across `layouts/` and the theme). Hugo resolves the current language, looks in this site catalogue first, then falls back to the theme catalogue, then to the key itself. Examples: `pagination`, `posts`, `postsOn` and `recent` are read by `themes/hugo-brewm/layouts/_default/list.html`; `redactionHistory`/`redactionNotes` by the notes single/partials; `protanopia` by the accessibility controls in the theme's `assets/js/accessibility.js`; `search` (theme-supplied) by `layouts/partials/search/pagefind.html`.

## Integration

- **Languages config:** `config/_default/languages.toml` defines the `pt-br` entry (`contentDir = 'content/pt-br'`, `locale = 'pt-BR'`); without that language table these strings would never be selected.
- **Theme:** depends on `themes/hugo-brewm/i18n/en.toml` as the key schema and `pt_br.toml` as the base translation; adding a key here that the theme later adds will silently shadow it.
- **Content:** `translationKey` front matter pairs English and Portuguese pages, so a translated page inherits this catalogue automatically.
- **Build policy:** `enableMissingTranslationPlaceholders = false` in `config/_default/hugo.toml` means a missing key renders nothing rather than a `[i18n]` marker, which is why the 13-key delta is kept complete.
